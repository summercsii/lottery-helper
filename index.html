使用說明

📋 基本步驟

  1. 匯入資料 — 貼上貼文網址搭配 Access Token 自動抓取留言，或使用手動匯入。
  2. 設定獎項 — 設定活動名稱、獎品名稱和中獎人數。
  3. 篩選條件 — 選擇要排除重複帳號、關鍵字篩選等條件。
  4. 立即開獎 — 點擊按鈕，系統以隨機演算法公平抽出得獎者！

🔑 如何取得 Access Token？

  1. 前往 Facebook Graph API Explorer
  2. 選擇你的應用程式和粉絲專頁
  3. 勾選需要的權限（pages_read_engagement）
  4. 點擊「Generate Access Token」
  5. 複製 Token 貼到本工具中

📝 手動匯入格式

每行一筆，格式為「名稱」或「名稱, 留言內容」：

王小明, 我要參加！
李小華, +1 抽起來
張大偉

⚙️ 篩選功能說明

  • 排除重複帳號：同一帳號多次留言，只算一次。
  • 排除重複中獎：同一帳號最多中獎一次。
  • 關鍵字篩選：留言必須包含指定關鍵字才符合資格。
  • 標記好友：留言中需標記指定數量以上的好友（@提及）。
